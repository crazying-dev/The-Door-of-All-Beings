# 众生之门 - 使用说明

## 快速开始

### 方法一：一键启动（推荐）

双击运行 `一键启动.bat` 文件，系统会自动：
1. 检查并安装服务器依赖
2. 启动游戏服务器
3. 尝试启动Unity项目

### 方法二：手动启动

#### 1. 启动服务器
双击运行 `start_server.bat` 文件

#### 2. 启动Unity
双击运行 `start_unity.bat` 文件，或在Unity Hub中打开项目

### 方法三：完整启动
双击运行 `start.bat` 文件，按照提示操作

## 首次运行配置

### 1. 配置数据库

在 `Server\.env` 文件中配置数据库连接：

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_NAME=the_door_of_bings
JWT_SECRET=任意密钥
PORT=7777
LOG_LEVEL=info
```

### 2. 安装依赖

首次运行会自动安装Node.js依赖，也可以手动执行：

```bash
cd Server
npm install
```

## 注意事项

### 重要提醒
1. **设备绑定**：每个账号只能绑定一个设备
2. **死亡惩罚**：角色死亡后数据会清零
3. **红名后果**：红名玩家无法接取高阶任务
4. **反作弊**：严禁使用外挂

### 常见问题

**Q: 服务器启动失败**
A: 检查MySQL服务是否启动，检查.env配置是否正确

**Q: Unity无法加载项目**
A: 确保Unity版本是2022.3.21f1或更高版本

**Q: 数据库连接失败**
A: 检查MySQL服务是否运行，检查用户名和密码

**Q: 设备绑定验证失败**
A: 确保使用相同的设备ID
